# BMS Project

A React + Vite + TypeScript landing page for a BMS / OEM equipment business.

## Features

- Modern responsive landing page
- Product showcase sections
- OEM and technology highlights
- Quote inquiry form with Supabase integration
- Tailwind CSS styling

## Local development

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open:

```text
http://localhost:5173/
```

## Production build

```bash
npm run build
```

## GitHub upload

```bash
git remote add origin https://github.com/<your-username>/<your-repo-name>.git
git branch -M main
git push -u origin main
```

If you have not created the GitHub repository yet, create it in the GitHub UI first and then push.
